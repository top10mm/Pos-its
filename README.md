## O que é?

**Meus Post-its** é um aplicativo para criar e organizar notas adesivas coloridas, como aqueles post-its de papel que a gente cola na mesa, só que sempre à mão no celular ou no computador.

- 📝 Crie, edite e exclua notas
- 🎨 Vários papéis de parede e cores para os post-its
- ✍️ Escolha a cor e o tamanho da letra de cada nota
- ↕️ Arraste as notas para organizar na ordem que preferir
- 🗑️ Lixeira com "Desfazer": notas excluídas podem ser restauradas em até 30 dias
- 💾 Backup e restauração das suas notas em arquivo
- 📴 Funciona offline depois do primeiro acesso
- 🔒 Suas notas ficam **somente no seu dispositivo**

## Como acessar

### 🌐 Pela web

Basta abrir no navegador:

**https://top10mm.github.io/Pos-its/**

### 📲 Instalar no celular ou computador

O app é um **PWA** (Progressive Web App): pode ser instalado e abre como um aplicativo normal, com ícone próprio.

| Dispositivo | Como instalar |
|---|---|
| **Android** (Chrome) | Menu ⋮ → **Instalar app** (ou "Adicionar à tela inicial") |
| **iPhone / iPad** (Safari) | Botão Compartilhar → **Adicionar à Tela de Início** |
| **Windows / Mac / Linux** (Chrome ou Edge) | Ícone de instalação na barra de endereço → **Instalar** |

Dica: dentro do app, clique no botão **?** (canto superior direito) para ver informações sobre o app e, se disponível, o botão de instalar.
